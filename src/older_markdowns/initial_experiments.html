And at this point, I think we are in business. Here is what we need to do. We need to run UMAP many times. We can produce a list of each run. We can then track a specific cell ID (eg. row 1). We can then plot its position across all runs. We can produce more sophisticated visuals later, but this is a place to start.

library(umap)

num_runs <- 100
dimr_list <- lapply(seq(num_runs), function(i) {
    set.seed(i)
    result <- umap::umap(cells, preserve.seed = TRUE)$layout %>% as_tibble()
    names(result) <- c("umap1", "umap2")
    return(result)
})

ggplot(dimr_list[[1]], aes(x = umap1, y = umap2)) + geom_point()

Ok, that looks like what we would expect to look like. Now what we are going to do is produce a new map that simply has one cell being tracked across each run.
